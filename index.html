Image → lossless pixel commands

Load PNG or another browser-readable image. Its decoded RGBA pixels are converted to compressed, editable text commands at the original pixel resolution. No resize, quantization, or color averaging.
Choose a raster image to produce a self-contained command list.
PNG 8-bit RGB/RGBA, indexed, and grayscale are decoded directly without canvas rounding, including transparent pixel bytes. Interlaced/16-bit PNGs use browser fallback. Metadata and ICC profiles are not stored; JPEGs are already lossy.

Precision text

Draw letters from actual browser font outlines with antialiasing, optional stroke, and shadow. The font must be available on the rendering device.
Commands: //font //textstyle //textalign //textoutline //textshadow //text.

Command reference + examples

Pixels start at (0,0) in the top-left. X increases right; Y increases down. center and percentages always use the selected canvas size. Use fg or bg for toolbar colors. Absolute coordinates are pixels. Example: center-100 or 75%. Radii can use pixels or percentages of the shorter canvas dimension.

Exact decoded RGBA imports
//clearalpha clears canvas to transparent pixels.
//pixels x y width height z64:BASE64 draws losslessly encoded RGBA tile data compressed with deflate. The Import image button generates these lines automatically. A raw r64: mode is also accepted. Run all renders the tiles as one undoable action; edit, reorder, or combine commands with other drawing tools. For exact matching, keep design/output at the native resolution with //sampling nearest.

Stroke width & brushes
//width 1..128 sets the default stroke width, also updates manual brush size
//brushshape square|round|diamond|spray|soft|calligraphy changes the brush used by manual painting and lines/curves
//stamp x y color [width] [brush] places one brush mark at a specific point
//stroke x1 y1 x2 y2 color [width] [brush] draws a stroke between coordinates (alias of //line)
//line x1 y1 x2 y2 color [width] [brush]: per-command width/type overrides defaults
/brush round|square|diamond|spray|soft|calligraphy selects a brush (and /brush round x y color [width] stamps)
Other outline commands such as //walls, //hrect, //hcyl, and //hpolygon honor the default width unless an explicit thickness is supplied. //brushsize n also updates the width default. Every stroke is undoable.

Pattern / mask controls
//palette name pattern save a reusable pattern
//seed 12345 deterministic random variation
//gmask #FF0000 edit only pixels of this color
//gmask !#FFFFFF edit all but white
//gmask %20 edit a random 20% of pixels
//gmask #sel restrict edits to the selected region
//gmask #existing edit non-background pixels
//gmask %30&#sel combine restrictions
//gmask clear mask
//opacity 35 blend drawing colors with existing pixels
//opacity 100 restore solid painting
Masks and opacity apply to script drawing commands, not to the manual pencil.
Finishing effects (on selected area)
//blur 6 softens pixels using a box blur
//outline #081225 4 adds an outer edge around pixels that differ from the background color
Use //sel first; both effects are undoable. Blur affects the selected rectangle; the outline stays inside it.
Reusable sprite presets (48×48)
//sprite icons_r00_c00 500 300 4
Places the sprite at X=500, Y=300 with nearest-neighbor scale ×4 (192×192 output). Transparent pixels are skipped. Use the sprite selector above to insert a preset.

Colors: #FF7A59, #F75, rgb(255,122,89), fg, bg. Patterns can mix colors with WorldEdit-style relative weights. Use //seed to make procedural patterns reproducible. The linear(...) pattern uses selection bounds if selected, otherwise the full canvas.

WorldEdit-inspired syntax: 2D commands such as //polygon, //gradient, //text, and //canvas are extensions. Not every original WorldEdit command is implemented.
